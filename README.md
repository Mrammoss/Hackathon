# Pothole Tracker

Pothole Tracker is a Ruby on Rails application for reporting and viewing potholes.

This repository can also be used as a workspace to experiment in `irb`, write Ruby code, and save notes by committing and pushing.

## Development

- Ruby version: `3.2.1`
- Install dependencies: `bundle install`
- Prepare the database: `bin/rails db:prepare`
- Start the application: `bin/dev`

Run the test suite with `bin/rails test`.
